# 叙事风格（骨架）

> 这是一份写作指导骨架。在 world.yaml 的 `writing:` 段声明它（取消注释 `kind: style` 那条），
> writer 就会在需要时按 `kind` 读取本文。删掉本注释，写你自己世界的风格约束。

描述这个世界的正文该有的**语气与视角**（第几人称、贴谁的感官、冷/热基调）。

描述**感官与环境**的密度（每段是否要有具体感官锚点、哪些标志性物件要活起来）。

描述**篇幅与节奏**（单次正文大致几段、句子长短如何交错）。

如有其他原则（认知迷雾、真实人性、禁止剧透玩家不可知信息等），一并列在这里——
writer 会把这些当作落笔与自检的依据。
